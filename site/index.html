BUILT FOR LISTENING

你真正会用到的能力，
都在播放链路里。

能力不堆在设置页里。播放、歌词、音乐库和系统控制彼此相连，才会让一款音乐应用真正顺手。

01

可靠的后台播放

基于 Media3 / ExoPlayer，支持队列、后台音频、暂停续播与播放状态同步。

02

歌词，有节奏地出现

支持 LRC / YRC、翻译、罗马音、逐字进度，以及独立歌词与系统媒体信息。

03

音乐数据不被打散

以网易云音乐为核心，保留歌曲、歌单、收藏、评论与音乐库的连续体验。

04

把系统也算进来

通知、锁屏、控制中心、系统媒体会话与设备厂商增强能力，都从播放状态出发。
