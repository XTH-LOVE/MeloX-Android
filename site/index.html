Track 03–05 · Full Album

整张专辑，
一首一首听。

功能不再摆成货架。点开每一首「曲目」——播放、歌单、系统、数据，MeloX 的全部家底都在里面。
03 / 05

播放要可靠——队列、后台、锁屏、音质选择都是核心体验。MediaSessionService 保证退到后台、锁上屏幕，音乐依然稳稳地走；每一次切歌的衔接，都由双播放器预加载和节拍分析提前算好。

  • MiniPlayer / Apple Music 风格 / Classic 播放器与横屏布局
  • 播放队列、下一首播放、手动队列、拖动进度
  • AutoMix 双播放器预加载、淡入淡出、智能过渡
  • 十段均衡器、节拍 / 速度分析
  • 睡眠定时、播放缓存、下载修复、离线播放
  • 锁屏信息、媒体通知与控制中心实时同步
  • 音质按账号权益自动匹配，最高母带级

不是套个搜索框。从每日推荐到私人 FM，从云盘到歌曲百科——你的账号、歌单和音乐资产完整迁移，在 MeloX 里都有正式的位置，不用将就。

  • Web / 扫码 / 手机号验证码登录，会话持久化
  • 首页推荐、发现、搜索、排行榜
  • 每日推荐、私人 FM、心动模式
  • 歌单、专辑、艺人、播客、评论、歌曲百科
  • 我喜欢的音乐、最近播放、歌单编辑
  • 云盘上传 / 删除与本地音乐库
  • 按权益请求标准 / 高品质 / 无损 / Hi-Res / 环绕声 / 母带

系统要真正参与——播放状态走到哪，通知、锁屏、超级岛就跟到哪。OEM 增强可用就用，不可用自动降级，核心体验从不依赖 Root。

  • 标准 Android 媒体通知与 MediaSession
  • 小米 HyperOS Focus Notification / Super Island
  • vivo OriginOS 原子岛尝试接入
  • 可变刷新率与系统动画倍率适配
  • 音量键桥接与触感反馈

账号、音乐库、下载与用户音源各自独立。第三方服务受接口变更、限流、地区或版权影响时，MeloX 会把失败当成失败处理，绝不拿试听片段伪造播放成功。

  • 严格匹配标题、主艺人与时长才算数
  • 可选解析服务的 API Key 只保存在本机
  • 签名热更新验签失败即回落内置行为
  • 歌词 AutoSync 在设备端用 ONNX 本地对齐，不上传你的音乐库
